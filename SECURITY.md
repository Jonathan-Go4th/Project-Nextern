# Security Policy

## Supported version

Security updates are currently provided for the latest published Nextern
release.

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| Earlier development versions | No |

## Reporting a vulnerability

Please do not disclose suspected security vulnerabilities in a public GitHub
issue.

Use GitHub's private vulnerability-reporting option when it is available for
this repository. Otherwise, contact the repository owner privately through
their GitHub profile.

Include:

- A description of the vulnerability
- Steps to reproduce it
- The affected screen, feature, or file
- The possible impact
- Any suggested mitigation

Please avoid accessing, modifying, or sharing data that does not belong to you.

The maintainers will review legitimate reports and coordinate remediation
before public disclosure.
