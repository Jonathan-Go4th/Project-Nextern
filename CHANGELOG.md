## [1.0.0] - 2026-08-02

### Added

- Complete learner and administrator Flutter application.
- Login and role-based navigation.
- Learner home screen and program discovery workflow.
- Program listing and detailed program information.
- Saved-program functionality.
- Program application and enrolment form.
- Learner tasks, learning progress, notifications, profile settings, and certificate viewing.
- Administrator dashboard and profile management.
- Program creation and program-management workflows.
- User-management and learner-profile workflows.
- Review-assignment and announcement functionality.
- Local application data and session persistence.
- Automated Flutter analysis and test workflow with GitHub Actions.
- Bug-report and feature-request issue templates.
- Pull-request template.
- Contribution, security, community-conduct, and MIT licence documentation.

### Changed

- Improved navigation and consistency across learner and administrator screens.
- Removed unused administrator-dashboard code identified during release analysis.
- Configured CI to report informational Flutter lints while continuing to reject warnings and errors.

### Quality

- Flutter analysis completes without warnings or errors.
- All 24 automated tests pass.
- Generated Flutter platform files are excluded from version control.

### Distribution

- Android release package planned as `Nextern-v1.0.0-android-universal.apk`.
