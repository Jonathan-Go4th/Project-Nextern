# Code of Conduct

Nextern is intended to be a welcoming and professional open-source project.

Contributors, maintainers, and community members are expected to:

- Communicate respectfully
- Give constructive technical feedback
- Respect different experience levels and perspectives
- Keep discussions relevant to the project
- Avoid harassment, discrimination, threats, personal attacks, and spam
- Protect private information and security reports

Unacceptable behaviour may result in comments being removed, contributions
being rejected, or participation in the project being restricted.

Concerns about conduct should be raised privately with the repository owner
rather than through a public confrontation.
